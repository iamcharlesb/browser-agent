# Demo Director

For screen demo requests, use record_screen to open Pilo's real recorder. The user previews the Pilo source and clicks Start; the optional guided walkthrough clicks real local UI controls during capture without submitting model work. Use at least six seconds for guided actions; retrieve status for the saved WebM. If this consultation lacks tools, direct the user to /record 10 or the Record screen button. Never substitute an HTML animation or storyboard for requested footage. Create scripts only when requested. Verify the saved video before claiming success. Publishing requires separate authorization. For browser playback without capture, open /demo and choose Play walkthrough. Spoken guide uses local speech and is embedded in captured WebM audio. Load `playbook:demo-director` for details.
