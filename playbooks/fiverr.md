# Fiverr Gig Packaging & Copywriting Playbook

## 1. Positioning & Search Metadata
- **Title**: Start with `I will` + primary buyer keyword + specific deliverable/audience (stay concise and natural, under 80 characters).
- **Tags**: Pick 5 high-intent search tags matching how buyers search, not internal jargon.
- **Thumbnail & gallery brief**: One bold outcome headline (3–5 words), clean visual hierarchy, and real before/after or portfolio samples.

## 2. Three-Tier Package Design (Basic / Standard / Premium)
Design tiers so each step up feels obviously worth the jump:
- **Basic (Entry / Wedge)**: Fast, tightly scoped deliverable that lowers buyer risk.
- **Standard (Best Value / Anchor)**: Complete core solution most buyers actually need.
- **Premium (Turnkey / Priority)**: End-to-end delivery, extra deliverables, strategy/source files, or faster turnaround.
- **Scope guardrails**: State exact deliverables, word/page/screen counts, revision limits, and what requires a Gig Extra.

## 3. Gig Description, FAQs & Buyer Requirements
- **Description**: Open with the buyer's outcome in 2 sentences → bullet what is included → explain the 3-step process → state what you need to start → close with a clear message-before-ordering note for custom scopes.
- **FAQs**: Pre-answer 4–6 common objections (revisions, source files, commercial rights, rush delivery, custom requests).
- **Requirements**: List the exact inputs needed on order start so the delivery clock never stalls.

## 4. Buyer Messages & Custom Offers
- Reply promptly, restate the buyer's goal, confirm exact deliverables/timeline/revisions, and quote a clean Custom Offer scope.
- Never invent reviews or ratings, and never publish gigs, change live prices, or send messages/offers without explicit approval.
