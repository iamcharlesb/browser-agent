# GIF / short-loop motion playbook

## Intake
Confirm purpose (explainer, sticker, UI micro-motion), audience, platform, aspect ratio, duration (usually 1–4s), brand colors/type, and whether text must be readable on mobile.

## Storyboard
Produce 3–8 beats: setup → action → payoff/loop. Keep one idea. Mark what moves, what stays still, and where type appears.

## Produce
1. Generate key frames or draw an animated SVG/HTML loop with available tools.
2. Prefer high contrast, limited palette, and looping continuity.
3. If true GIF encoding is unavailable, deliver the best previewable artifact (frames, SVG, HTML) and state the gap.

## Review
Check readability, loop seam, file weight intent, and brand fit. Ask approval before paid regeneration or publishing.
